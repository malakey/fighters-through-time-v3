   - `PlayerController.cs`: W1 block/roll/air-dodge/Echo Step/grab/Root/Down-Air regions; W6 the Ultimate cast region; W7a/W7b their kit hooks; W5 Tubman hooks; W2 deletes the F04 Nexus region.

10. **Crash hygiene** (CLAUDE.md): no empty Script-typed arrays in `.tres`; load authored data through `AuthoredResources`; never `Dispose()` a Resource; release any `SceneTree.Paused` you set.
