## 1. Shipped

### The F10 attempt record

- **New `scripts/Core/StoryAttemptState.cs`** — `StoryAttemptStatus` (7 members),
  `StoryRecoveryCause`, `StoryRewardSourceState`, and the record classes
  `StoryCheckpointRecord`, `StoryPendingHealing`, `StoryRewardSourceRecord`,
  `StoryPlayerResourceTimers`, `StoryRecoveryEvent`, `StorySealReadiness`,
  `StoryCompletionTransaction`, `StoryAttemptState`. Every field in the contract's ownership table is
  present, normalized and round-trips.
- **`StoryAttemptState.CreateFresh`** mints an ID; the **only two callers** are fresh level entry
  (`BeginLevelRun` non-resume branch) and an explicit full Restart Level. A scene reload, a hub
  return, a checkpoint, a death and an Anchor Snap all keep the same ID.
- **`Bump()`** is the monotonic revision; every committed change moves it once.
- **`MigrateFromLegacyRoot(save)`** derives a record from the six loose V7.3 fields. A payload parked
  mid-level (non-empty `LastCheckpointID`) cannot have its anchors, Defy or claims reconstructed, so
  it is **preserved untouched** with zero anchors, `DefyHistoryUsed = true` and status
  `LegacyRecoveryRequired`; `StoryManager.PendingAttemptNoticeKey` surfaces
  `save_notice_legacy_recovery_required`. A payload between levels migrates cleanly. Idempotent.

### Act III gauntlet

- **Anchor charges.** `StoryManager.AnchorChargesFor(Difficulty)` = Easy 3 / Normal 2 / Hard 1;
  `AnchorChargesRemaining` / `AnchorChargeMaximum`; `SpendAnchorCharge()` (1 → 0 completes).
  Initialized **only** in `MintFreshAttempt`. Publishes `EventBus.RaiseAnchorChargesChanged`
  (A8 renders the pips).
- **Anchor Snap.** `BeginAnchorSnap(checkpointID, cause)` — same attempt, one charge spent, the same
  20% undeposited-dust fee, full HP, full difficulty rewind pool, checkpoint Integrity allowance
  (timer cause → A3's `ResolveTimerRecoveryIntegrity`), the recovery event committed **before**
  presentation, pending healing cancelled without refund, then the level reconstructed **in place**.
- **Smothered.** `EnterSmothered(checkpointID, cause)` — persists the terminal status **before** the
  presentation, charges the failure fee exactly once (re-entry is a no-op), and routes to
  `res://scenes/ui/GameOver.tscn`. `RestartFromGameOver()` is the only door out.
- **`ResolveActIIIFailure`** picks between them; **`BeginTimelineCollapse` branches to it** for
  Levels 13–15, so both designed triggers (timer-zero and a lethal event with no rewind charge) are
  caught at one chokepoint. A3's `ActIIICollapseOverride` is armed by `BeginLevelRun` with
  `RunActIIICollapseBeat`, which plays the ordinary fracture beat first.
- **No-hub chaining.** `StoryLevelControllerBase.PresentCompletion` routes an Act III results panel's
  Return to `LoadCurrentLevel()` (the level advance already happened) instead of `ReturnToHub()`.
  Level 15 never reaches it.
- **Completion auto-deposit.** `CommitCompletionTransaction(levelID)` runs inside `OnLevelComplete`,
  before the results overlay, and calls `DepositDustToActiveSave()` for Act III only — the gauntlet's
  single banking event, "sealed through the Beacon".
- **Hard's three anchors.** The inert-middle rule is now the pure static
  `StoryLevelControllerBase.IsMiddleAnchorInert(level, role, difficulty)`; Act III is exempt.

### Load routing, durability, N05

- **`RouteResumeByAttemptStatus`** drives `ResumeCampaign`: Smothered → Game Over; Act III
  Active/RecoveryPending parked in a level → that level; everything else → the hub. No path runs
  fresh-entry initialization.
- **Latest-durable restore.** `StoryLevelControllerBase.RestoreSavedCheckpoint` no longer means
  "checkpoint-time HP/meter" — it restores the durable values, folds the uncredited Rally meter in

  gauge and keeps a PreBoss lock locked; `CheckpointIntegrityPercent` is only the paid allowance.

  `RunQueuedWrite` (obsolete revisions dropped, an older write never replaces a newer one) +

  `WrittenRevision(slot)` + `LastStoryWriteFailed` + `WriteFailedNoticeKey`.
  `StoryManager.CaptureDurableSnapshot` runs once per live second from `_PhysicsProcess`.
- **Reward-source and healing ledgers.** `TryIssueReward` / `TryCollectReward` / `IsRewardClaimed` /
  `IsRewardPendingPickup` / `RewardSource`; `CommitFontChannelCompletion` / `CreditPendingHealing` /
  `CancelPendingHealingForRecovery` / `TryConsumeHealingPickup` / `IsHealingPickupConsumed` /
  `HasGrantedCheckpointBenefit`.
- **N05.** `StoryManager.RequiredEndingLevelIDs(heroID)` (exactly 15), `ResolveEndingPointTotal`,

  `RecordLevelResultToSave` prefers it.
- **Test seam.** `StoryManager.SuppressSceneLoadsForTesting` + `LastRequestedScenePath`; every scene
  change now goes through `RequestScene`.

## 2. Not delivered, and why

1. **Per-level authored encounter baselines.** The record, registry and hook all ship; the default
   derivation (`{LevelID}_wave_N` from anchor order) matches only 6 of the 14 campaign controllers.
   Authoring real tables means editing fourteen files. **Open, owner Unassigned** — §9 item 4 has the
   per-level survey and the acceptance criterion. Nothing reads the baseline to respawn encounters
   yet, so the default cannot mis-restore anything today.
2. **`playerResourceTimers` has one writer.** Only `TimeFreezeCooldownSeconds` is populated. Block
   charges/regen/lockout, ability and Echo Step cooldowns, `RallyUncreditedMeter` and the D02d
   Wardenclyffe delay are persisted fields with no publisher — they belong to A1b, A1c and A2.
3. **The Snap's authored 3 s presentation.** Gameplay is complete; the fracture-reassembles beat is
   an `EnvironmentNotice` line today. A8 owns the shared rewind overlay.
4. **A write failure does not block the transition.** `PersistAttempt` returns the result and the
   notice is raised, but the Snap/Smothered routes proceed. Closing it needs a UI surface nobody owns
   this package.
5. **`StoryLevelControllerBase.IsActIII` was left wrong for Level 4A** rather than redefined
   mid-wave. See §9 item 2 — it should be deleted or redefined at closeout.
6. **`localization/en.en.translation` is NOT committed** (§2.11), and the `.import` line-ending churn
   from the local `--headless --import` was reverted.

## 6. `AGENTS.md` / `CLAUDE.md` edits required (Phase C — A3b touched neither file)

**New contracts to add:**

- **The Act III Gauntlet.** Levels 13–15 play back to back with no hub return; the hub is unreachable
  until campaign completion; level completion routes to the next level and its auto-deposit is the
  only Act III banking event; **all three Act III checkpoints are active on Hard** (the inert-middle
  rule is Acts I–II only).
- **The Warden Beacon** (`scripts/Environment/WardenBeacon.cs`, group `warden_beacon`): opens the
  existing Repository at any *activated* Act III checkpoint, spends previously deposited dust only,
  offers no Deposit action. `ResonanceProgression.SpendableBalance` is the rule's single statement.
- **Anchor charges** Easy 3 / Normal 2 / Hard 1 per Act III level, initialized only on fresh entry or
  an explicit full Restart Level; `EventBus.OnAnchorChargesChanged`.
- **Anchor Snap** replaces Timeline Collapse's hub extraction in Act III (same 20% fee, full HP, full
  rewind pool, one anchor; 1 → 0 completes), and **Smothered** is the game's only Game Over
  (`scenes/ui/GameOver.tscn`, Restart Level / Quit to Menu; persisted before its presentation; Quit
  and Load return to it; deposited dust always safe).
- **The Resonance Hold**: Act III keeps the Integrity clock but it measures the hero's resonance;
  the **candle rule** (full kit at 1% as at 100%); the drain stand-ins `ResonanceHoldNode` /
  `ResonanceHoldVariant` (severed conduits L13, cradle intake valves L14, anchor pylons L15), each an
  `ChronalExtractor` subclass carrying the identical drain weight and dust share.
- **F10 persistence**: `StoryAttemptState` + `StoryAttemptStatus`; attempt IDs minted only on fresh
  entry and full Restart Level; load routing driven by `attemptState.status`; **ordinary loading
  restores the latest durable HP/meter/Integrity, not checkpoint values** (this supersedes AGENTS.md's
  V7.3 wording about `RestoreSavedCheckpoint` restoring checkpoint-time HP and meter); the ordered
  per-slot async writer with revision guard; the per-second durable snapshot;
  `save_notice_write_failed`; the `LegacyRecoveryRequired` migration rule.

  unrounded 750-point comparison, identical on every difficulty. AGENTS.md's
  `EndingThresholdPercent`/`IntegrityByLevel` prose should say the value read is the **PreBoss-locked**
  gauge.
- **New systems for the inventory:** `WardenBeacon`, `ResonanceHoldNode`, `GameOverScreen`,
  `StoryAttemptState`, and the template `scenes/templates/ResonanceHoldNodeTemplate.tscn`.
