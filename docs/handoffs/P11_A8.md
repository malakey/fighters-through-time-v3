## Shipped

### Story HUD — scene and script rewrite (HUD_CONTRACT)

`scenes/ui/StoryHUD.tscn` and `scripts/UI/StoryHUD.cs` were rewritten, not edited. The tree is
now the contract's `SafeArea / TopLeft_Panel / TopRight_Panel`, and the widgets that used to be
built at runtime are authored nodes.

- **Two status slots** at 28 × 28, damage left / control right, in a fixed-position
  `StatusEffects_Panel`. An empty slot hides its glyph and radial and keeps its reserved space.
  Distinct glyph plus localized name per status — never colour alone.
- **Duration radials** on both slots, and readiness radials on the three cooldown icons and the
  Ultimate ring, via the new `scripts/UI/RadialProgress.cs` (`_Draw` arc; the repo had no radial
  widget at all). Fill is written by the owner of the authoritative value, never self-ticked.
- **Ability slot lock overlays** (`Cooldown1..3_LockOverlay`, `UltimateMeter_LockOverlay`) showing
  Dormant / Suppressed / Clear. Locked slots are shown, never hidden, and a locked slot is never
  "ready" however full its cooldown or meter.
- **Defy seal** (20 × 20, beside the Ultimate ring), four states, shape-distinguished, no pulse.
- **Time Freeze indicator**, separate from the rewind counter, with Ready / active countdown /
  cooldown countdown and a thaw warning in the final second.
- **Beacon anchor pips** (Act III only), data-driven count like the block pips.
- **Rewind counter** icon + `×N`, red at 1, dimmed empty hourglass at 0, no alarm.
- **Persistent dust counter** in the top-right with a separately fading `+N` float (1.0 s). The
  balance reads the committed wallet; the float is cosmetic and cannot move it.
- **Integrity era-clock**: wedge, text, siphon streams bound to the live Extractor count, frozen
  state rendered as its own tint. Replaces a percentage label that inferred "draining" from a
  frame-to-frame fall.
- **Collapse Tremor** overlay at levels 0/1/2.

### Fighter HUD

Two 24 × 24 status slots per player (damage left / control right on **both** sides), a Defy seal
beside each meter, F21's mode-switched stock display, the `00:10` red pulse with a single chime
on the Critical Cues path, and F22's "Sudden Death — next death loses" replacing the running
clock. Nodes renamed `Root → SafeArea`, `PlayerOne/Two → P1_Status/P2_Status`.

### F24 ownership outline

`assets/shaders/outline_glow.gdshader` gained `owner_outline_color` / `owner_outline_thickness` /
`owner_outline_enabled` and a second composite pass drawn **after** the effect edge.
`GlowPresentationController.SetSlotIndicator` writes that independent channel instead of pushing
onto the arbitrated effect stack, so no status, armor, spawn aura or expiry can recolor, pulse,
disable or replace it. Per-actor `ShaderMaterial` isolation is proven, not assumed.

### C01a Reduced Temporal Effects

New `scripts/Core/ComfortSettings.cs` static read point, `GlobalSaveData.ReducedTemporalEffects`
(additive, default false, never inferred from Screen Shake), pushed at boot by
`SaveManager._Ready` before the first loading/portal effect and live from the Settings toggle.

### C01b prioritized audio

`AudioSnapshotMixer` converted from an additive stack to a priority selector; five new ladder rows
as silent placeholders; the Pause `+2 dB` UI lift removed and UI dropped from the mixed buses;
`CriticalCues` and `Dialogue` buses added; the background low-pass moved off the SFX parent onto
its three World SFX children; the dialogue chirp routed to `Dialogue`; `AudioManager.PlayCriticalCue`
added.

### C01c binding shape

`InputBindingSet` gained `UnboundActions` and `ShortcutEnabled` (both keyed `action|deviceKind`),
surviving `Normalize()`. New `InputShortcuts` owns the three fixed recipes, the direct action
names, and the reachability rule. `Actions.Ultimate` moved into `RemappableActions`;
`RestorableActions` now unions the C01c direct actions. The Controls tab lists every bindable
action with keyboard / gamepad / **Unbind** / reset, plus per-device shortcut toggles and a
localized unreachable-route explanation.

### Chronal Rating retirement (ruling 2.A)

`results_rating` deleted, `LevelResultsPanel.RatingLine` gone, `StoryManager.LastLevelChronalRating`
and the `RatingByLevel` write removed. `StorySaveData.RatingByLevel` stays as documented dead data.

### F05 results itemisation

`LevelResultsPanel.ShowResults` widened to six categories (required enemies, boss, Extractors,
optional/secret, losses, tier bonus). Losses subtract and show on their own line; the tier bonus
adds. **A10 supplies the values.**
