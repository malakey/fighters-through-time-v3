## 3. The one thing every other agent should read

**`FTT.Core.CharacterRoster` requires the Godot runtime.** Reading the manifest goes through
`Godot.FileAccess`; GdUnit runs suites without `[RequireGodotRuntime]` in a plain .NET host where that
call is an **access violation** (`0xC0000005` in `godotsharp_string_new_with_utf16_chars`) that kills
the test host mid-run. It surfaces as `Test host process crashed : Fatal error` **after** a plausible
`Passed!` line — easy to misread as CLAUDE.md failure signature 5. It is **not catchable**: `try`/
`catch` cannot see a native AV.

Two instances were found and fixed here, both introduced by this pass:

- `GlobalSaveData.UnlockedCharacters`'s **field initializer** crashed `BasicStringProfileTests`.
- Moving the fill into **`GlobalSaveData.Normalize()`** did not help — `FighterMatchStatisticsTests`
  calls `Normalize()` directly and crashed identically.

**The rule: `GlobalSaveData` is a plain data class with no engine dependency and must stay one.** The
roster grant is now `SaveManager.EnsureRosterUnlocked(GlobalSaveData)` (`internal static`, idempotent),
called from every path that hands out a global payload: the no-save-key branch, the no-file branch,
the successful load, the legacy migration, the corrupt-fallback branch, and `SaveGlobalData`.

The same caution applies to `CampaignCaptiveRoster` and `ContentManifest.LoadDefault()`.

## 6. `AGENTS.md` / `CLAUDE.md` edits required (Phase C — A6b edited neither)

**AGENTS.md**

1. **Roster section** — add the standing mandate verbatim: *the roster will grow; never hardcode
   roster size or enumerate the cast in load-bearing ways.* State that `FTT.Core.CharacterRoster`,
   backed by `content_manifest.csv`, is the single runtime roster and that every production consumer
   reads it. Soften "The initial roster is **fixed** at nine characters" to "is nine today".
2. **New contract, `DEFER-ROSTER-ENUM`** — `FTT.FighterSim.FighterCharacterID` is the one documented
   exception and is **append-only**: a new member takes the next ordinal, no member is reordered,
   renumbered or reused, and `zoneTypeID = (int)id * 10 + slot` must stay unique. Its ordinals
   serialize into snapshots and the network protocol, so a tenth character is a protocol-affecting
   change needing a rollback and protocol pass.
3. **New hard rule under coding conventions** — *`GlobalSaveData` and the other save payload classes
   are plain data with no engine dependency. Never read a resource, a manifest or any `res://` path
   from a payload field initializer or from `Normalize()`: pure-C# GdUnit suites construct and
   normalize them with no Godot runtime, where a `FileAccess` call is an uncatchable access violation
   that kills the test host. Engine-side defaults belong on the autoload.*
4. **Visual grammar** — record the two-colour contract and that `UIPalette` owns both families
   (`UnboundCold*` / `Resonance*` / `WardenPortal`), that no siphon, extractor or beam site may define
   its own cold literal, and that `ResonanceGrammarTests` enforces it. Note the "two kinds of door"
   rule (Unbound rifts jagged and cold, Warden portals clean and steady) established in Level 0.
5. **Glow arbiter** — A8's handoff already asks to correct "three independent channels" to four. It is
   **five** now: base tint, tint override, arbitrated outline stack, A1's Suppression smother, A8's
   F24 ownership edge — plus A6b's persistent hero aura. State that the aura is Story-only and that
   Suppression drains rather than clears it.
6. **`CharacterData`** — note the three `Placeholder*Color` presentation exports and that
   `CharacterFactory` no longer holds a colour table.
7. **Test baseline** — +8 from A6b.

**CLAUDE.md**

8. **Add a failure signature** (it belongs beside 1/2/4/5/6): *a **crashed test host** —
   `The active test run was aborted. Reason: Test host process crashed : Fatal error.` with
