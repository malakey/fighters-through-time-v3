### Framework fix (shared file, small): variant completion

`StoryLevelControllerBase.HandleDialogueComplete` now compares **base** IDs
(`DialogueSequenceData.BaseIDOf`). A hero variant completes under its own ID, so before
this a variant exit (`level_02.exit@joan`, and every other shipped exit variant) never
presented the results and a variant post-boss beat (`level_08.postboss@cleopatra`)
stalled the chain. `OnDialogueSequenceComplete` hooks now receive base IDs.
`Level01Controller` (which does not extend the base) got the same fix.
