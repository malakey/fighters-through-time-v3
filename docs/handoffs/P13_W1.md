## What shipped

### A01 — two-charge Specials and the Shield-Breaker class (both modes)
- `FTT.Combat.BlockClass.ShieldBreaker = 4` appended (ordinals 0–3 unchanged). `HitClassification.IsShieldBreaker`.
- `BasicComboRules.SpecialBlockChargeCost = 2` is the one value. `BlockRules.ChargeCost(attackClass, charges, shieldBreaker = false)`: Special → `min(2, charges)`, Shield-Breaker → all. A non-shattering blocked Special gets the ordinary 8-frame shieldstun (the existing non-shatter branch).
- Story: `HitPayload.ShieldBreaker`, `Hitbox.ShieldBreaker` (set by `ApplyAbilityHitContract`, only honoured on a Special-class payload), `BaseSpecial.WithAbilityContract` stamps it from `AbilityData.BlockClass` for Special-class, non-Construct payloads. **Not** done through `BlockChargeCost = 2`, so Shield of Orléans' Guard-Crush refund (`BlockChargeCost >= 2`) still excludes player Specials.
- Sim: `FighterDamageRules.ApplyFighterHit(..., shieldBreaker)`; the class rides the projected `FighterAbilityHitData.BlockClass` (`.ShieldBreaker`) for melee intents (`AttackIntent.Special(...)`), projectiles (`ResolveProjectileContract(..., out contract)`) and zone pulses (`FighterZoneSystem` now takes the `FighterHitContractTable`, wired in `FighterSimulation`).
- Data: `BlockClass = 4` on `joan/special_2.tres`, `lincoln/special_1.tres`, `lincoln/special_2.tres`.
- Story construct hits are Basic-class: serpent nest bite, vine snare, and the Cataclysm coil burst (hitbox ID `coil_burst` kept, now an explicit parameter).
- Copy (value edits only, keys unchanged): `systems_card_block_body`.

### D10 — signed knockback vectors (sim)
- `FighterAbilityHitData.HasKnockbackVector / KnockbackX / KnockbackY` (loadout only, no snapshot state): `|x|` and Godot-Y-down → sim-Y-up signed `y`.
- `ApplyFighterHit(..., hasKnockbackVector, knockbackVertical)`: horizontal magnitude pushed away from the hit origin, vertical signed (negative = spike), both scaled by weight and low-HP. The historical scalar path is byte-identical when the flag is off.
- Converted: melee Special intents, Special projectiles, the Emancipator and Tempest zone pulses, the Down-Air slam. **Not converted** (still the `max(|x|,|y|)` tuning scalar in `FighterTuningComponent`): Ultimate intents/zones/finales (W6's region), the Spirit Strike eagle (W5 replaces Pocahontas), and Ultimate-origin projectiles.

### A03 — air dodge (both modes)
- `UniversalMovementRules.AirDodge{Startup=4, Invulnerable=8, Recovery=10, TotalFrames=22}`, `AirDodgeShiftUnits = 1.0`; `UniversalMovementPhase.AirDodgeStartup/Invulnerable/Recovery = 5/6/7` (appended; kit phases stay 16–20).
- Sim: `FighterAirDodgeRules` (`TryStart`, `Advance`, `IsAirDodge`, `IsInvulnerablePhase`, `Refresh`). `AirDodgeUsed` lives on component **320** (plan D7; no new ID). Refreshed on landing, ledge grab and stock loss (observed via the respawn platform). Pushbox off in the invulnerable phase; combat-locked throughout; jumps withheld; landing does not cancel it (grounded remainder decelerates). Legal from Airborne and an aerial swing's recovery/chain window (the same Roll press cancels the string first). Driver presents it as `Rolling` / `roll`.
- Story: `PlayerController` `_airDodge`/`_airDodgeUsed`, `TryStartAirDodge`, `ProcessAirDodge` (shift through `MoveAndCollide`), `IsAirDodging`, `AirDodgeUsedThisAirtime`. `CheckRollInput` routes airborne presses to it and `ProcessAirborne` now polls Roll.
- Copy: `movelist_roll` (value edit).
