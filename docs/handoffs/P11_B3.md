## Defect found, not fixed — read this before Phase C

`LegacyLevelControllerBase.ParSeconds` is `public abstract int` and **hides** A3's
`StoryLevelControllerBase.ParSeconds` (`public virtual float`). The compiler has said so since the
Wave 1 merge: `CS0114` at `LegacyLevelControllerBase.cs:170`, one of the three build warnings.

It is not cosmetic. `StoryLevelControllerBase._Ready` calls
`story.BeginIntegrityClock(ParSeconds, _extractors.Count)` through the **base** member — still `0` for
every Legacy Level — and the next line early-returns on `ParSeconds <= 0f`. So **no Level 4A variant
starts an Integrity clock**, and `SetRecoveryRouteSeconds(id, ParSeconds * …)` books a zero F11
recovery budget at both checkpoints. All nine variants are affected, Einstein's included.

A variant cannot repair it from its subclass — the name is shadowed by the intermediate abstract. The
fix is in `LegacyLevelControllerBase`: make it `public abstract override float ParSeconds`, or rename
the Legacy member and override the base one. Both B3 suites assert `ParSeconds > 0`, which reads the
*int* and passes, so nothing currently catches it; a Phase C pin should assert the clock actually
starts for a 4A variant.
