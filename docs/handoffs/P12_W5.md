# P12 W5 — Fighter mode flow (handoff)

Branch `p12/W5`. Items: hazard On/Off toggle with per-stage cadence, M23, M24 (per adopted D5(b)), M25, H05/G01 (per adopted D4(a)), M26, G15a, G15b, G12. Placeholder presentation throughout; nobody has played any of it.

## What shipped

### Hazard On/Off (2026-09-26 design)
- `HazardTriggerFrequency` is **deleted** from `MatchSettings` and `GameManager`. `MatchSettings.StageHazardsEnabled` (default On) is the only hazard rule.
- Per-stage cadence: `FTT.FighterSim.FighterHazardCadence.AuthoredFrames(hazardType)` in `FighterEntitySystems.cs` — the single canonical table, **2700 frames for all ten stages**, seeded from the retired Medium interval so a default match is unchanged.
- Sim: `FighterMatchRules.HazardFrequency` → `HazardCadenceFrames` (resolved at construction; 0 means "the stage's authored cadence"). `FighterMatchComponent.HazardFrequency` → `HazardCadenceFrames` in the **same slot** (component 301 did not grow for it). Overtime / Sudden Death still halve the idle gap and recovery.
- A positive cadence override is a **test seam** only; values below `FighterHazardCadence.MinimumOverrideFrames` (60) throw, so a stale 1–3 frequency ordinal cannot silently become a cadence. Tests that were written against the old High interval now pass `hazardCadenceFrames: 1800` explicitly (stage suites, hazard-behaviour harness, geometry sweep, Sudden Death cadence, StocksLost).
- Selectors replaced by a toggle in CharacterSelect (`RulesRow/StageHazards`), the Holodeck/Versus CPU panel (`TogglesRow/StageHazards`) and the drill rules (`CalibrationDrillRunner.DrillMatchSettings`, hazards Off).

### Save: declared v7 derivation (NO version bump)
- `SavedMatchSettings` gained `bool? StageHazardsEnabled` (nullable on purpose: null = pre-toggle payload) and `bool MeterPickupsEnabled`. `HazardRate` is kept as a **legacy read-only** field and is no longer written.
- **Derivation for Phase C:** `SavedMatchSettings.DeriveStageHazardsEnabled(int legacyHazardRate)` → `legacyHazardRate != 0` (Off → false, Low/Medium/High/unknown → true). Pure, engine-free.
- Until Phase C, `Normalize()` applies `StageHazardsEnabled ??= DeriveStageHazardsEnabled(HazardRate)` — idempotent, never overwrites an explicit value.
- `GlobalSaveData.PlayerSlotPalette` (int, default 0, clamped 0–2 in `Normalize`) — additive; no derivation needed.

### M23 — orb spawning (`FighterOrbSystem`, `FighterOrbSpawnRules`)
- Seeded gap per spawn inside the frequency window, floored at **600 frames**: Low 3000–4200, Medium 1200–1800, High 600–720 (each centred on the fixed interval it replaces). First gap drawn at world init (only when items are on).
- Anchor = seeded pick among **free** authored anchors; an anchor already holding an orb is skipped; all occupied → no spawn. Draw order per attempt: next gap, effect, anchor. 15 s lifetime unchanged (`LifetimeFrames` 900). Collection is still overlap ("walk through").

### M24 — Resonance Surge
- Effect type **4**, +15 meter clamped at 100 (`FighterOrbSystem.ResonanceSurgeEffectType`, `FighterOrbSpawnRules.ResonanceSurgeMeter`).
- Behind the new Items sub-toggle **Meter pickups** (`MatchSettings.MeterPickupsEnabled`, `FighterMatchRules.MeterPickupsEnabled`, `FighterMatchComponent.MeterPickupsEnabled` — one new int on component 301, now ~108 of 128 bytes). **Off by default** → default draw stays `NextInt(0, 4)`. Only rides on Items being on (`RulesFor`).
- `FighterProxyStyle.PaletteEffectFor` maps sim types onto the shared colour table explicitly (fixes a pre-existing ordinal-cast bug that painted Chronal Haste in the meter gold). Surge = meter gold.
- Story pickups: no en.csv value outside `fighter_*`/`holodeck_*`/`match_*` contains "orb" — pinned by `FighterFlowRoutesTests.NoStorySurfaceCallsAPickupAnOrb`. No Story copy needed changing.

### M25 — Fighter HUD cooldowns
- `FighterCooldownSlot.Ultimate` → `EchoStep` (ordinal 3). Four authored 20×20 icons under `Body/Column/PipRow/Cooldowns/{S1,S2,Movement,EchoStep}_Cooldown` each with a `Radial` (`RadialProgress`), beside the block charges; P2 authored mirrored. The old code-built `Body/Column/Cooldowns` plates are gone.
- Radial fraction = elapsed share of the cooldown, denominator latched from the authoritative remaining count when it rises (no second copy of any cooldown length; refunds/rollback corrections move the arc). Echo Step reads `FighterVerbComponent.EchoStepCooldownFrames` (new optional arg on `FighterHUD.ApplyPlayerState`) and dims below `BasicComboRules.EchoStepMeterCost` (30). Brief ready flash via tween. Glyph text never changes.

### H05/G01 + M26 — Fighter menu, Versus CPU, origins
- New `scenes/menus/FighterPlayOptions.tscn` + `FighterPlayOptionsScreen`: Local Versus / Versus CPU / Remote Play notice (DEFER-STEAM-RPT) / Back. MainMenu's Fighter button now loads it (one-line change in the Fighter entry).
- `SessionData.FighterMatchOrigin` (`LocalVersus | VersusCpu | Holodeck | Drill`), never persisted. `ReturnToHubAfterFighterMatch` is now a **property view** over it (true ⇔ Holodeck). New one-shot flags `ArriveAtHolodeckConsole`, `ReopenHolodeckConsole`.
- `FTT.UI.FighterFlowRoutes` is the single statement of every exit: pause Exit (`LocalFighterPause.ApplyPauseExitToSession`), results buttons (`MatchResults.ApplyResultsAction`, buttons built from `ResultsActions(origin)`), select Back.
- Local Versus: CPU toggle and CPU difficulty **removed** from the select; two human tokens only.
- Versus CPU: P1-only select; locking P1 opens `HolodeckConsolePanel { FrontEnd = true }` over the select (no drills entry, origin VersusCpu); its Back unlocks P1. Results: Change Fighters → P1 select, New Stage → config panel (via `ResumeAtStageSelect`), exit → Fighter menu.

- Drill: `CalibrationDrillList.ApplyDrillToSession` sets origin Drill; exits stay on `CalibrationRoute`.
