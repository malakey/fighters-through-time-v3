## 1. What shipped

### The ability

`scripts/Environment/TimeFreezeController.cs` (new) — Story-only, **5.000 s = 300 ticks**, **no
charges / no meter / no dust**, **45 s cooldown armed at thaw** (including an early end), identical
on all three difficulties, legal at **zero** death-rewind charges, and **not** lockable by
Suppression (the eligibility rule takes no status at all, which is how the carve-out is enforced).

- Ticks in `_PhysicsProcess` at `ProcessMode.Inherit`, so `SceneTree.Paused` stops both the duration
  and the cooldown for free. **The controller never writes `SceneTree.Paused`** (pinned).
- The cooldown also pauses during a death rewind, the collapse beat and an active dialogue sequence
  (`IsPresentationHolding`).
- Ends early and cleanly on death/respawn, and in `_ExitTree` (scene transition / level exit).
- Registered by `StorySceneBootstrapper.Attach` under the existing `includeRewind` flag — level-only,
  never the hub — and exposed on `StorySceneServices.TimeFreeze`.

### The world freeze

- New `IStoryTimeFreezable { void SetTimeFrozen(bool frozen); }` in
  `scripts/Environment/StoryRewindPolicy.cs`. **Deliberately not `IStoryRewindSimulation`** — see §9
  deviation 1: the rewind freeze cancels attacks and zeroes velocity, which would destroy the
  "resume preserved positions, velocities and attack phases" contract.
- Swept groups (`TimeFreezeController.FrozenTimeGroups`): `Enemies`, `persistent_construct`,
  `story_hazard`, `puzzle_object`, `story_loot`, `rescuable_npc`, `time_freezable`, mirror group.
  **`chronal_extractor` is deliberately absent** — Timeline Integrity keeps draining.
- `ProcessMode.Disabled` fallback (`ProcessFallbackGroups`) for **pooled projectiles/zones only**:
  `story_projectile`, `enemy_projectile`, `story_zone`. Both sides' projectiles freeze **in place**;
  nothing is cleared. All `ProcessMode` writes go through `PhysicsSafeSetters.SetProcessModeSafe`.
- Room scoping: the freeze is level-wide, and `RoomTransitionTrigger.ActivateRoom` calls
  `TimeFreezeController.FreezeActivatedRoom(GetTree())` immediately after enabling the encounter
  root, so a room revealed mid-freeze is frozen **before** its actors take a tick.
- Enemy invulnerability is one gate at the shared chokepoint `Hitbox.OnAreaEntered`, in front of
  `Hurtbox.TakeHit`: a player-sourced hit on a non-player target is **discarded** (no damage, no
  stagger, no Rally echo, no meter). The read is side-effect-free (safe inside the physics flush).
  Because checkpoint fractures and extractors are `EnvironmentHurtboxAdapter`s at owner index −1, the
  same gate also blocks checkpoint activation and extractor destruction.
- Player mask: `PlayerController.TimeFrozen` allows Move/Jump/Down/Roll and **refuses, without
  buffering**, basic attacks, grabs, Special 1/2, the ultimate, Echo Step and the Movement Ability.
  Ability cooldowns (`UpdateCooldowns`), block-charge regen (`BlockSystem`) and status durations
  (`StatusController`) are suspended; `InteractionArea.TryInteract` refuses (no puzzle progress).

### Input, persistence, HUD, tutorial

- `project.godot`: action renamed `gameplay_rewind` → `gameplay_time_freeze`, **both events
  unchanged** (physical keycode 82 = `R`; joypad button 4 = Back/Select).
- `InputManager.Actions.TimeFreeze`; `RemappableActions` and `ActionLabelKey` updated; the
  "no `GameplayButtons` bit" Story-only guarantee kept and pinned.
- `InputBindingSet.MigrateLegacyRewindAction()` renames a saved `gameplay_rewind` override onto the
  new action, **never overwriting an explicit newer Time Freeze bind**, and is idempotent.
  **Phase C must call this from the single v5→v6 migration step** (A2 wrote the function only).
- `StorySaveData.TimeFreezeCooldownSeconds` (additive, field initializer, no migration needed);
  `StoryManager.TimeFreezeCooldownRemaining` + `SetTimeFreezeCooldown` wired into
  `ClearLevelAttemptState` (fresh entry / Restart → Ready), `WriteAttemptStateToSave` and
  `RestoreAttemptStateFromSave` (resume restores). Activation stores the conservative **45 s**;
  an explicit Save/exit ends the freeze and stores 45 s; a reload never resumes a freeze.
- `StoryHUD`: `_rewindCooldownPip`, `RefreshRewindCooldownPip()` and the `_rewindManager` lookup are
  **deleted**. Nothing else in that file was touched. A2 publishes
  `EventBus.OnTimeFreezeStateChanged`; **A8 authors the indicator node.**
- `TutorialCalibrationStep.UseManualRewind` → `UseTimeFreeze`; `RegisterManualRewindComplete` →
  `RegisterTimeFreezeComplete`; `SkipManualRewindLesson` → `SkipTimeFreezeLesson`. The scripted
  death-rewind demo stays ahead of it.
- `Level00Controller` (manual-rewind step region only): the drill is an invulnerable blocker between
  the player and a safe destination, with `DrillFreeFreeze` giving a ready freeze on **every** retry
  and a never-strand skip when no controller exists.

## 5. API the other workstreams must call

**A5 (Level 0 / Legacy Unlock):**
- `TimeFreezeController.TryBeginTimeFreeze()` — **exact name, as contracted.** Returns false and
  changes nothing when ineligible.
- `TimeFreezeController.DrillFreeFreeze { get; set; }` — ready-on-every-retry for the drill; clear it
  when the lesson ends. The only recharge bypass in the game.
- `TutorialCalibrationStep.UseTimeFreeze`, `TutorialCalibrationScript.RegisterTimeFreezeComplete()`,
  `SkipTimeFreezeLesson()`.
- `StorySceneServices.TimeFreeze` is the scene's live controller.

**A8 (HUD):**
- Subscribe to `EventBus.Instance.OnTimeFreezeStateChanged` → `TimeFreezePayload { TimeFreezeState
  State; float SecondsRemaining; }`, `TimeFreezeState` = `Ready | Active | Cooldown`.
- String keys, as constants so a rename is a compile error:
  `TimeFreezeController.ReadyLabelKey` (`hud_time_freeze_ready`), `.ActiveLabelKey`
  (`hud_time_freeze_active`, `{0}` = seconds), `.CooldownLabelKey` (`hud_time_freeze_cooldown`,
  `{0}` = seconds), `.ThawWarningLabelKey` (`hud_time_freeze_thaw`), `.ThawWarningSeconds` = 1 s.
- Or poll the live node through `TimeFreezeController.ControllerGroup` (`"time_freeze_controller"`):
  `IsFrozen`, `FreezeSecondsRemaining`, `CooldownRemaining`, `IsReady`.
- **The indicator must be its own node.** Never attach this cooldown to the rewind counter — that is
  the pattern the design now forbids and the pip A2 deleted.

**Wave 2 / Phase C:**
- `InputBindingSet.MigrateLegacyRewindAction()` — call from the single v5→v6 migration step.
- `StorySaveData.TimeFreezeCooldownSeconds` — already additive; needs no migration branch.
- `StoryManager.EndActiveTimeFreezeForExplicitSave()` — call from any **new** explicit save/exit
  surface. Background autosaves must **not** call it.
- New freezable world objects: implement `IStoryTimeFreezable` (latch a flag, mutate nothing else)
  and join one of `TimeFreezeController.FrozenTimeGroups`, or
  `TimeFreezeController.FreezableGroup` if the class has no natural group.
