### Declared v6→v7 derivation (Phase C must compose; NOT wired)
`StoryAttemptState.ReconcileUndepositedCompletion(StorySaveData)` is pure, engine-free and returns the amount it deposited.
- **When it deposits:** `LevelChronalDust > 0` **and** one of the following:
  - the attempt status is `Completed`; or
  - the payload has the v6 post-completion shape: an unminted attempt record and an empty `LastCheckpointID`, which is what `SaveLevelCompletion` leaves when the player quits before the hub loads.
- **What it does:** deposits the wallet to `DepositedChronalDust[SelectedCharacterID]` exactly once, then zeroes the wallet. The function is idempotent.
- **What it leaves alone:** held dust from a Collapse (a minted `AwaitingHubResume` record) and a live attempt are never banked.
- **Ordering:** it must run in the v6→v7 envelope step, **before** `MigrateFromLegacyRoot` mints an ID for the unminted record. Otherwise the second clause can no longer see that shape.
- **Tests:** `CompletionReconciliationDerivationTests` (3).

### GAP-01 — ordinary loads preserve combat resources
- **Publisher.** `StoryManager.CapturePlayerResources(save)` runs inside `WriteAttemptRecord`, so every checkpoint (`SaveManager.SaveCheckpoint`), durable snapshot, Collapse, Snap and critical event publishes the full `StoryPlayerResourceTimers`.
  - It also writes the paired `CurrentUltimateMeter`, because the uncredited Rally meter only means something as a pair with the meter.
  - It is gated on `IsLevelTimerRunning` and on a minted attempt, so a hub or post-restart player can never "refill" the record.
- **`PlayerController` region** (additive, after `UpdateCooldowns`): `RallyUncreditedMeter`, `CaptureStoryResourceTimers(timers)` and `RestoreStoryResourceTimers(timers)`.
  - Ability cooldowns are keyed by `LegacyUnlockSchedule.SpecialOneKey`, `SpecialTwoKey` and `MovementKey`.
  - `BlockCharges < 0` means "never captured" and restores nothing.
- **`BlockSystem`** (additive): `RegenProgressSeconds`, `LockoutRemainingSeconds` and `RestorePersistedState(charges, regen, lockout)`.
- **Restore.** `StoryLevelControllerBase.RestoreDurableResources(player, save, resumedMidLevel)` is public static and shared by the base and Florence (`Level01Controller`).
  - It settles the uncredited Rally **once** into the meter, capped at 100, and writes the settlement into the attempt record and `save.CurrentUltimateMeter` together.
  - It restores timers only on a mid-level resume.
- **Tests:** `StoryResourceTimerPersistenceTests` (3). They use a real depleted hero, a JSON round trip through `SaveSchemaMigrator`, a repeated reload both after and before the settled write, an Anchor Snap, and a check that a fresh entry never inherits a stale record.
