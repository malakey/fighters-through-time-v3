## 6. Recommended strategy
1. Keep every node name, path and type; change look and geometry. For the Story corner cluster, add the vitals / abilities / time-tools grouping as visual backgrounds (`PanelContainer` / `NinePatchRect`) behind or around the existing containers rather than reparenting; if reparenting is wanted, edit `StoryHudContractTests.ContractNodes`, `StoryHudPresentationTests`, `StoryHudBeaconAnchorTests`, `ResolveUI` together.
2. Keep glyph widgets as `Label`s (tests read `Text`); add a `TextureRect` icon child, or move the seams to model values and change the tests. Keep icons distinct per status and Defy state (shape carries state).
3. Bars: theme `ProgressBar` `fill`/`background`; keep the Fighter HP fill a `StyleBoxFlat` (or change `TintFill` to `SelfModulate` on a textured fill).
4. Sizes via `custom_minimum_size`; the Beacon 24/8 pins must be edited for bigger sizes.
5. Fighter top bars: re-anchor `P1_Status` / `P2_Status`; keep `Body/Portrait`, `Body/Column/...` and `MatchClock`; rewrite only `PlayerPanelsAnchorToTheBottomAndTheClockStaysTopCenter`; keep `Cooldowns` under `PipRow` (or edit `FighterHudSceneTests:161-164` and `FighterHudContentTests:100-103`); leave room for `MatchClock`.
6. Boss bar: add a nameplate and PHASE tab as new siblings under `BossPanel` (keep `BossName`/`BossBar`/`PhaseNotches`), fed from `OnBossPhaseChanged`; one new key.
Risks: at 2x and 1.4 scale the clusters may collide with `BossPanel` (top-centre) and `LevelTitle`/`Objective`; the top Fighter band is shared with `MatchClock` and maybe KO presentation (`FighterPresentationOverlay` / `FighterCamera` unchecked); the `TintFill` trap; bots do not read the HUD.
